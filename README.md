# 👁️ Real-Time Object Detection for Visually Impaired

## 📌 Description
This project is designed to assist visually impaired individuals by detecting objects in real-time using a camera and providing voice feedback.

---

## 🚀 Features
- 🔍 Real-time object detection
- 🗣️ Voice output for detected objects
- 🎥 Works with webcam / DroidCam
- ⚡ Uses SSD MobileNet

---

## 🛠️ Technologies Used
- Python
- OpenCV
- TensorFlow
- NumPy
- pyttsx3

---

## ▶️ How to Run

1. Clone the repository:
```
git clone https://github.com/chetangupta1705/real-time-object-detection-for-visually-impaired-person.git
```

2. Install dependencies:
```
pip install -r requirements.txt
```

3. Run the project:
```
python main.py
```
